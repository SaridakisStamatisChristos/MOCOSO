# G11 research generalization gate — alternate 240-case holdout

**2026-10-27.** Run separately from the 171-case square/powers/suffix-fault suite. This is exploratory **within-repository** evidence, not statistical or worldwide SOTA certification.

## Frozen input design and independent check

- 10 deficit levels: 19,24,32,48,60,64,65,75,90,110.
- 3 lengths per deficit: h+2, h+15 and h+160.
- 8 families per length: increasing random positive slopes, almost convex with internal perturbation, quadratic plus bounded jitter, flat values, uniform random signed, broken terminal suffix, an explicitly constructed feasible one-omission witness, and an explicitly constructed feasible many-omission witness.
- Seed 734120, full input digest SHA256, Python/environment and source hashes retained; compare G8 (corrected validation), G10, and G11 using the same arrays, warmups and multiple complete witness timings.
- **Exact full-witness equality** checked for all executed methods on every case. Do not time an answer later rejected for correctness.
- Both feasible and infeasible instances retained; report every losing cell. Synthesized feasible families guarantee at least one valid omitted-subset witness without assuming which solver's answer is optimal.

The independent holdout does **not** make G11 universally fast. It is intended to invalidate overfitted engineering thresholds when input structure changes.

## Local source-subset execution

Command: `PYTHONPATH=/mnt/data/mocoso_sota python /mnt/data/mocoso_sota/g11_holdout.py` (experimental local harness; the repository equivalent is `python benchmarks/g11_rfp_holdout.py --repeats 5`).

240 cases; all complete outputs matched among corrected G8, unchanged G10, and the G11 hybrid. Of these, 60 were feasible. On the same local host, comparing **G8/G10 medians**, G8 was faster in 113/240 cases; G10 in 125/240; 2 ties or exact ratio 1. On h=19..64, G8 was faster 73/144, G10 70/144, one tie. Among the 60 feasible cases G8 won 31, G10 29, with median G8/G10 = 0.688. This contrasts with the earlier 171-case benchmark, where G10 was particularly competitive for power sequences.

Those conflicting results show that **representation/content distribution affects the winner**; a predetermined dispatch based solely on h cannot be asserted globally optimal.

## Interpretation and next gate

The main publishable question remains whether G10's exact high-modulus *joint time-space bound* follows directly from known lexicographic resource-constrained path methods. The G11 engineering mixture is not a new mathematical theorem. The holdout helps select future empirical work; it does not justify rewriting the G9/G10 manuscript, claiming external SOTA, or altering production.
